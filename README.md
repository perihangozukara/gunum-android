# Günüm for Android

Android shell (Capacitor) for the [Günüm](https://github.com/perihangozukara/gunum) daily planner. The app itself lives in the `gunum` repository; this project wraps it so it can be installed on a phone.

## Build
1. `npm install`
2. Copy the web app into `www` and run `npx cap sync android` (the `aktar.ps1` script does this on my computer)
3. Open the `android` folder in Android Studio and run it on a phone

Built with the help of an AI coding assistant as part of my learning journey.
